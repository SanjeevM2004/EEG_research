# 📈 Results & Visualizations

This directory stores the outputs of the training and evaluation processes.

## Contents

- **Confusion Matrices**: `cm_*.png` files showing the classification performance (True vs. Predicted classes).
- **Classification Reports**: `*.txt` files with detailed Precision, Recall, and F1-scores per class.
- **Training Logs**: Loss curves and accuracy plots.
- **Benchmarks**: Excel files (`*.xlsx`) comparing GADCN against baselines on BCI IV 2a and Physionet.
- **Paper Figures**: Generated figures used in the ICML 2026 paper submission.

## Key Figures

| Image | Description |
| :--- | :--- |
| **`classification_report_gcn.png`** | Performance metrics for the GCN-based model. |
| **`cm_true_norm_gcn.png`** | Normalized confusion matrix for GCN. |
| **`individual_and_average_erp_*.png`** | Event-Related Potential (ERP) plots for different time windows. |
